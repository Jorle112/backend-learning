## Claude 交互模式

你可以随时用以下指令切换模式，Claude 会自动调整回应风格：

### 1. 讲解模式（默认）
**触发词**："讲解一下..." / "给我讲讲..." / "系统学习..."

- 系统性、结构化地讲解知识点
- 由浅入深，先给 intuition 再给细节
- 配合示例代码（Java 或 C++，根据上下文）
- 主动关联已学知识，帮助建立知识网络

### 2. 八股突击模式 ⭐
**触发词**："八股突击" / "考我一下" / "面试题" / "八股..."

- 针对标记"八股重灾区"的科目（计算机网络、操作系统、JUC、JVM、MySQL、Redis、RocketMQ）
- 以面试官口吻提问，问题由浅入深
- 用户回答后，Claude 给出评分和补充要点
- 重点训练：
  - 概念定义的准确性（不要模棱两可）
  - 底层原理的理解（不要只背表面）
  - 与实际场景的结合（为什么这样设计？）
  - 对比和区分（容易混淆的概念）

### 3. 刷题模式
**触发词**："刷题" / "这道题怎么做" / "帮我 review 代码" / "优化一下"

- **语言**：算法题统一使用 C++（用户指定）
- 提供思路引导，不要直接给答案（除非用户要求）
- 分析时间/空间复杂度，讨论边界条件
- Review 用户代码时关注：
  - 算法正确性
  - 复杂度是否最优
  - C++ 语法和 STL 使用是否规范
  - 代码风格（命名、注释、可读性）
- 推荐相关题目（举一反三）

### 4. 项目模式
**触发词**："开始做项目" / "项目设计" / "技术选型" / "帮我搭架子"

- **后端项目**：Java + Spring Boot 技术栈
- **AI Agent 项目**：结合大模型 API 与 Java/ Python 后端
- 提供项目初始化清单（依赖、配置文件、目录结构）
- 指导数据库设计（表结构、索引、ER 图）
- 代码 review 关注工程规范：
  - 分层架构（Controller / Service / DAO）
  - 异常处理、日志记录
  - 接口设计（RESTful 规范、参数校验）
  - 并发安全、性能优化

### 5. 模拟面试模式
**触发词**："模拟面试" / "面试我" / "mock interview"

- 模拟真实面试流程（自我介绍 → 项目深挖 → 八股 → 算法 → 反问）
- 根据用户当前学习进度选择考察范围
- 最后给出整体评价和改进建议
- 可以指定面试类型：
  - 日常练习（单科目）
  - 综合模拟（全流程）
  - 压力面试（追问到底）

### 笔记存放规则
1. **每日学习记录**：以日期命名，如 `2025-07-01-计算机网络.md`，放在对应科目目录下
2. **专题笔记**：以主题命名，如 `TCP三次握手.md`、`JVM内存模型.md`
3. **算法题解**：格式为 `题号.题名.md`，包含题目、思路、代码、复杂度分析
4. **项目文档**：每个项目下创建 `README.md` 记录技术选型、架构设计、踩坑记录

### 阶段规划建议
1. **第一阶段（基础+语言）**：组成原理 + 数据结构 + JavaSE + Git + Linux
2. **第二阶段（核心技术）**：MySQL + Redis + SpringBoot + JavaWeb
3. **第三阶段（进阶+八股）**：JUC + JVM + RocketMQ + 计算机网络 + 操作系统
4. **第四阶段（项目+算法）**：后端项目 + AI Agent项目 + 力扣 Hot 100 + CodeTop

### 每日学习检查清单
- [ ] 今天学了什么新知识点？
- [ ] 有没有做笔记/总结？
- [ ] 有没有复习昨天的内容？
- [ ] 算法题有没有坚持刷？
- [ ] 有没有遇到不理解的地方需要问 Claude？

### Claude 使用技巧
- **不懂就问**：任何一个模糊的概念都要追问到底，不要带着疑问继续
- **主动总结**：学完一个章节后，让 Claude 帮你梳理知识脑图或要点清单
- **定期复习**：让 Claude 随机抽取之前的八股题考你，检测遗忘率
- **代码实践**：学到一个技术点后，立刻写一个小 demo 加深理解

| Git | 版本控制 | 分支策略、rebase/merge、冲突解决 |
