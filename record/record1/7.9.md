## 找素数
```java
for (int i = 2; i <= 100; i++) {        // 从2开始，1不是素数
    boolean isPrime = true;              // 先假设 i 是素数
    for (int j = 2; j * j <= i; j++) {
        if (i % j == 0) {               // 找到能整除的 → 不是素数
            isPrime = false;
            break;                       // 不用继续查了
        }
    }
    if (isPrime) {                       // 内层循环结束，标记还在 → 真素数
        System.out.println(i);
    }
}
```
